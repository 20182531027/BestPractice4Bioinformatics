# 数据清洗需要的统计学基础

## 1. 常见问题

### 1.1 数据质量评估
临床数据在采集过程中常出现三类问题：
- **缺失值**：可能是未检测（如未做某项检查）或录入遗漏。处理时需要区分：
  - 随机缺失：可删除或插补（均值/中位数）
  - 系统缺失（如某科室未检测特定指标）：需标记为特殊值（如`NA`）
- **重复值**：常见于：
  - 同一患者多次录入（ID重复）
  - 时间序列数据的时间点重叠
- **数据类型错误**：典型表现如：
  - 文本型数值（"120/80"血压记录）
  - 分类变量拼写不一致（"Male"/"M"）

如何决策？
```text
是否影响分析? → 是否可修正? → 是否代表真实异常?
    ↓             ↓              ↓
   删除        修正/插补        保留+注释
```

### 1.2 临床特异性问题（需要经验辅助）
临床数据的特殊错误需要医学知识辅助判断：
```python
# 示例：异常值逻辑检查（Python伪代码）
if (性别 == "女") & (前列腺特异抗原 > 4):
    标记为"可疑错误"
elif 收缩压 > 300:
    检查单位是否为"mmHg"
```

## 2. 数据描述与分布

### 2.1 描述性统计指标
| 指标类型       | 临床应用场景                  | 注意事项              |
|----------------|-----------------------------|---------------------|
| 均值           | 正态分布数据（如身高）        | 受极端值影响大        |
| 中位数         | 偏态数据（如住院天数）        | 更反映典型情况        |
| 标准差         | 评估检测指标波动性            | 需结合均值解释        |

### 2.2 分布形态分析
- **偏态数据**处理流程：
  ```mermaid
  graph LR
    A[绘制直方图] --> B{是否对称?}
    B -->|是| C[使用参数检验]
    B -->|否| D[考虑数据转换]
  ```

- **典型偏态指标**：肿瘤标志物浓度、ICU住院时长

> 先判断分布是否一般，再做严格判别。

## 3. 异常值排查与处理

### 3.1 检测方法对比
| 方法          | 适用场景                    | 阈值规则              |
|---------------|---------------------------|----------------------|
| Z-score       | 近似正态分布               | |Z| > 3            |
| IQR           | 任意分布                   | Q1-1.5IQR ~ Q3+1.5IQR |
| 临床标准      | 生理指标                   | 如血钾3.5-5.5mmol/L  |

Z-score, 标准分数，表示一个数据点与均值的距离，以标准差为单位。公示如下：  

$ Z = \frac{X - \mu}{\sigma} $，其中：  
$X$ 是观测值或数据点。  
$μ$ 是数据集的均值。  
$σ$ 是数据集的标准差。


## 4. 数据可视化方法

### 4.1 单变量可视化示例
**箱线图解读要点**：
- 四分位点：Q1、Q2（中位数）、Q3
- 下须线：Q1 - 1.5IQR（IQR:InterQuartile Range,即四分位距）
- 上须线：Q3 + 1.5IQR
- 离群点：Outlier，超过须线的独立点

### 4.2 多变量关联分析
**散点图矩阵**可快速发现：
- 线性相关性（如BMI与血压）
- 群体分层（如年龄相关的指标变化）
