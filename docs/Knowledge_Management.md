做科研，尤其是生物信息方向、注重方法学开发的同学，往往面临着海量信息的收集、整理和查阅的需求。建立有效的知识管理体系，有助于提高学习与研究效率，确保研究的连贯性和可重复性，同时便于团队协作和成果分享。一个好的知识管理体系能够将分散的知识整合成结构化的知识资产，为科研工作提供强大的支持。

# 1.信息收集

### **文献阅读渠道**

1. 通过 [PubMed](https://pubmed.ncbi.nlm.nih.gov/)、[Web of Science](https://www.webofscience.com)、[Google Scholar](https://scholar.google.com) 等学术数据库中搜索与研究主题相关的文献。

    1. 善用筛选，如查询最近5年文献、选取Research、Review等特定文献类型，并按引用率排序
2. 通过关注的期刊杂志定时阅读最新论文，如 [Nature](https://www.nature.com/research-analysis), [Cell](https://www.cell.com), Science 及其子刊。
3. 其次是从社交媒体（X, Research Gate, 知乎，微信公众号）获取知识。

##### RSS？

RSS 是 Really Simple Syndication 的缩写，即简易信息聚合，是一种基于 XML 标准的应用，用于聚合网站内容，提供了一种信息传播的平台，使得用户可以在一个地方获取多个网站的更新信息。

合理使用RSS，可以同时订阅多个学术期刊、专业数据库、研究机构网站等的 RSS 源，一旦这些网站有新的文献更新，RSS 阅读器会自动获取并展示标题和摘要等基本信息，用户无需逐一访问各个网站，便能快速了解大量文献的更新动态，从而筛选出与自己研究相关的文献进行深入阅读，大大提高了信息获取和阅读的效率。

但在移动互联网和社交媒体蓬勃发展的当下，RSS 的光芒被大大掩盖，很多主流网站不再提供 RSS 订阅入口或停止维护订阅源，像 Google Reader 等曾经知名的 RSS 阅读器也退出了市场。但 RSS 仍未完全消亡，仍有部分专注于内容分享的站点支持 RSS 订阅，一些技术爱好者和专业人士仍在使用 RSS 进行信息获取。

如何找到支持RSS的新闻源？[https://docs.rsshub.app](https://docs.rsshub.app)


### 文献资料下载

* 公共图书馆 如 [深圳图书馆](https://www.szlib.org.cn/)

* 社交网络、论坛等

* 其他网络途径
  * 补充一个国内文献互助的平台 [科研通](https://www.ablesci.com)

### 网络资料

利用浏览器的收藏夹或工具如 Pocket、Pinboard 收藏有价值的网页和在线资源，如生物信息学工具的官方网站、教程、**数据库**等。同时，可以使用印象笔记、有道云笔记等笔记工具的浏览器插件，快速剪辑网页内容保存到笔记中。

# 2.知识整理

### **知识分类**

按照研究项目、主题、方法等维度对知识进行分类，为每类知识赋予独特的编码。例如，将生物信息学方法分为序列比对、基因预测、表达分析等类别，并对每个类别下的知识进行编号，便于检索和管理。

#### Tips：为什么用markdown？

在信息时代，软件的更新换代非常频繁。许多专有笔记软件可能会因为公司战略调整、技术更新等原因而停止维护或发生重大改变，这可能导致用户之前记录的笔记无法正常打开、编辑或者数据丢失。

Markdown 作为一种标记语言，其本质是纯文本文件。它不依赖于特定的软件来呈现和编辑内容。无论是在简单的文本编辑器，如 Notepad（Windows 系统）或者 TextEdit（Mac 系统），还是在功能强大的代码编辑器（如 Visual Studio Code）中，都可以方便地创建和编辑 Markdown 文件。

* Markdown 的语法设计非常简洁，易于学习和记忆。这种简洁的语法使得用户可以专注于内容本身，而不是被复杂的排版操作所干扰。
* 在学习场景中，简洁的 Markdown 排版可以帮助学生快速整理知识点。
* 在工作场景中，如进行项目策划或者会议记录，Markdown 的格式排版可以让内容结构清晰，方便团队成员之间的阅读和共享。
* 与 ipynb（Jupyter Notebook 文件格式）或 Rmd（R Markdown 文件格式）等可交互代码文本的结合是 Markdown 的一大亮点。这些文件格式本身是基于 Markdown 的扩展，它们允许用户在同一个文档中编写 Markdown 文本和可执行的代码单元。
* 纯文本文件使得它们非常适合进行版本控制（如git系统）
* 纯文本也使得markdown可以很容易地被各种工具用于建立索引，如结合LLM外挂RAG构建知识库。（LLM和RAG的架构方法五花八门，但使用的数据是始终如一的）


### **建立备份机制**

定期对知识库进行备份，防止数据丢失。可以将备份存储在不同的设备或云端，以降低风险。例如，将知识库备份到本地硬盘和云端存储服务中，确保在任何情况下都能恢复数据。

### 知识分享与合作

**团队知识共享**

在一个科研团队中，建立团队共享的知识库，使用笔记工具的共享功能或专门的团队知识管理平台，如 飞书、Notion、钉钉、~~SharePoint~~ 等，方便团队成员共享和协作编辑知识。这有助于提高团队的沟通效率和工作协同性，促进知识的传播和共享。

**学术交流与合作**

积极参与学术会议、研讨会等活动，与其他科研工作者进行交流合作，分享各自的知识和经验。同时，可以通过学术社交平台如 ResearchGate 等，与全球的科研人员建立联系，分享知识库中的部分内容，获取更多的信息和灵感。

# 利用 AI 工具辅助管理

### **AI 驱动的文献管理工具**

如 Readwise、Space 等，可以自动整理和提炼文献中的关键信息，提高知识管理的效率。这些工具可以快速阅读文献，提取出重要的概念、方法、结论等，并将其整理成结构化的知识条目，方便存储和应用。

### **写作助手**

如 ChatGPT 、Deepseek等，可以帮助整理和总结知识，提供写作建议和思路。在撰写科研论文、报告等过程中，可以利用写作助手快速组织语言，提高写作效率，同时也可以借助其对知识进行梳理和总结，确保内容的准确性和完整性。
